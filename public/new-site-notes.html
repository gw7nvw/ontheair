Upcoming changes at parksnpeaks.org

Welcome to ontheair

After many years the old parksnpeaks.org server has reached end of life, and a significant amount of work would be required to rewrite the existing site to work with modern software versions. Instead, at Allen’s request, ontheair have agreed to provide all the services formerly provided at parksnpeaks.org through the ontheair server.

The new VK-specific version of ontheair is now available for you to try out at:

https://new.parksnpeaks.org

Feel free to take a look now, and get in touch if you have any questions or queries. The new site looks very different from the current parksnpeaks.org – it is largely map driven for a start. But all the current features provided by parksnpeaks should be there.



Activating your account:

If you already have an ontheair account, you can log in using that. Otherwise - all parksnpeaks user accounts have been copied over with the exception of your passwords. If you want to sign-in and send spots or alerts from the new website then you will need to set up a new password on the new server.

To achieve that, you have two options:

  • If you have access to the email address you used to register with parksnpeaks.org, then click the Password Reset link below, or find the link at the top of the sign-in page.

  • If you cannot access that email account, you will need to register a new account on the new server using the Create Account button below or the Sign Up link in the black menu bar at the top of the home page.



If neither of these options work for you, then get in touch with me, mattbriggs@yahoo.com and I'll help get things working for you.

A bit about the new site:

All pages on the site can be accessed from the menu bar at the top of the screen.  ontheair is designed primarily for desktop use, though the spotting system has been well tested on mobile devices.  Many features are only available to signed-in users, so please sign-in to see the full site.

Map:

  • On a desktop, the map will take up the left-hand half of the screen, showing locations of references in VK across all award programmes.  You can filter the map by clicking on the layers icon (looks like a stack of paper), and change between topographic and satellite view (OpenHikingMap and Sentinel2 cover VK).  On a mobile device the map is hidden by default.  You can use the Smaller Map / Larger Map buttons on the purple actions bar to enlarge it or make it go away, and on a touch device swipe right to switch to map view and left to switch to text view  

Spots and Alerts

  • Spots and alerts can be accessed on the spots / alerts pages from the black menu bar at the top of the screen. The spot page updates itself every minute, but note that security settings on some mobile devices do not permit web-page auto-updates when the browser is minimised. The new sites shows spots created locally, and those created at: POTA.app, SOTAwatch, HEMA.org.uk, LLOTA.app, WWFF spotline.

  • Add Spot and Add Alert buttons are present on the home page and the spot/alert pages for logged in users

  • Spots created at the new ontheair site will be forwarded, as appropriate, to: WWFF spotline, POTA.app, HEMA.org.uk, LLOTA.app, and SOTAwatch (see following note regarding mobile phone number validation for SOTAwatch)

SMS Spotting:

  • To use SMS spotting, or to send spots to SOTAwatch, you will need to register your mobile phone number against your account. For SOTA spots you also need to have registered this same phone number with the SOTAWatch site.

  • The new VK SMS gateway phone number for ontheair is: +61 406 705011

     

Logging / spotting apps:

  • Existing iPnP users will be able to continue to use the service without change (though an upgrade to the latest iPnP 3.2 is recommended – coming out soon!). Your existing parksnpeaks APIKey can still be used to access ontheair from that app, but for new users or devices, please enter the PIN (from your user profile on the new site) in the app for authentication

  • Existing VKPortalog users currently using their parksnpeaks website password within the VKPortalog app will need to set up that password on the new server (see above) for the app to continue to work after the old server is switched off.

  • Ham2k POLO will be unaffected by this change

     

Spot notifications:

  • ontheair offers notifications of all new spots across all portable award programmes through ‘push’ notifications to your mobile device (or browser extension). Push notifications require a pushover account and that the pushover app be installed on your mobile device / browser. Instructions for setting up pushover with ontheair are in the user's guide (under the Info menu on the new website). A one-off charge applies for use of pushover (after a 30 day free trial) - the money goes towards the maintenance of the pushover server which is used to route notifications to your mobile device, not to us at ontheair.

  • For those not wanting to install pushover, email notifications are also available, but the only cover spots/alerts created locally at ontheair, and not those from remote sites such as POTA.app and SOTAwatch.



There are many other features at ontheair, too many to describe here, but the above list covers the most important.  Full details of how to use ontheair are in the Users Guide, which can be found in the Info menu.
